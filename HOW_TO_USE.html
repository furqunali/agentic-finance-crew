Agentic Finance Crew — How to Use

AI expense-approval system · Company guide for Sugarland Petroleum · Tip: File → Print → Save as PDF

1. What this system is

An AI expense/reimbursement approval system. You send it an expense request and it returns a decision: AUTO-APPROVED (small, compliant, low-risk), NEEDS HUMAN REVIEW (over limit / breaks a rule / high-risk / possible duplicate → goes to a review queue for a Finance Manager), or REJECTED (invalid). Every decision is saved to a database, gets a full audit trail, and is protected by login + roles.

Safety by design: the AI only explains and recommends. A fixed, tested rule makes the final call and a human signs off on anything risky — the AI can never silently approve spend on its own.

2. ⚠️ Does it read PDF / images / Excel / CSV?

CSV now works through the web console's Bulk Upload tab; other file types are on the roadmap.

So today you can upload a CSV or enter one expense on the Submit form. Excel → save as CSV first. PDF/image receipts still need a reader built.

What I can still add (in order of usefulness)

  • Native Excel (.xlsx) upload → skip the "save as CSV" step.
  • PDF / image receipt OCR → extracts amount / vendor / date from a receipt, then checks it. (bigger job)
  • PDF report export → results export as CSV today; PDF can be added.

5. How to run it (one-time setup)

Needs Python 3.11+ (or Docker).

Option A — Python

cd "Agentic Finance Crew"
pip install -e ".[dev]"
uvicorn app:app --port 8000

Open http://localhost:8000/ — the web console (log in admin / admin on first run). Submit, Bulk Upload (CSV), Review Queue, Decisions + audit trail, Overview charts, dark mode and a 🔊 Listen button. The technical API explorer is at /docs.

Option B — Docker

docker compose up --build      # API on http://localhost:8000
Set these before real use (don't leave defaults): ADMIN_PASSWORD, JWT_SECRET (long random string ≥32 chars). For company data, use PostgreSQL via DATABASE_URL then run alembic upgrade head.

6. Day-to-day use

  1. Log in for a token (in /docs click Authorize).
  2. Submit an expense (POST /approve) → get decision, risk, reason, record_id.
  3. Finance Manager checks /review-queue and approves/rejects with an optional note.
  4. Auditor pulls the full trail any time (/decisions/{id}/audit).

Fields you send: id, employee, category (travel/meals/software/equipment/other), amount, has_receipt, plus optional description, currency, date. The spend limits can be tuned to SLP's real policy — give me the numbers.

7. What it does / does NOT do yet

  • ✔ Reads CSV (Bulk Upload) and exports results to CSV — new.
  • ✗ Native Excel .xlsx (save as CSV first), PDFs, image receipts (OCR) — see §2.
  • ✗ Email/Slack notifications to approvers.
  • ✗ PDF report file (CSV export works today).
  • ✗ Connect to SLP's real expense/accounting system.

None are blockers — all can be added.

8. Data & privacy

  • All sample data is fictional — no real SLP financial data included.
  • Passwords are stored as secure salted hashes, never plain text.
  • Login secret & DB credentials come from the environment — never in code.
  • Keep JWT_SECRET, ADMIN_PASSWORD, DATABASE_URL off shared drives and out of email.
